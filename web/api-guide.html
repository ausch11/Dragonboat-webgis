舟行 API 文档

同源 JSON API。登录成功后服务器设置 HttpOnly Session Cookie，同时返回 csrf_token。修改收藏、管理数据和提交反馈时，将该值放入 X-CSRF-Token 请求头。管理员权限在服务器校验。

请求路径说明
GET/api/health服务和数据库健康检查
GET/api/config应用日期、地图配置、助手模式
POST/api/auth/loginusername、password
POST/api/auth/registerusername、password、display_name；只能创建普通用户
GET / POST/api/auth/me / /api/auth/logout查询登录状态 / 注销会话
GET/api/events公开赛事的筛选、分页和收藏状态
GET/api/events/{id}已发布赛事详情
GET/api/venues / /api/rules比赛地点 / 知识资料
POST / DELETE/api/me/favorites/{id}添加 / 取消当前用户收藏
POST/api/assistant/queryquestion、可选 location；返回 answer、sources、events、engine
POST/api/feedback登录用户提交 content
GET / POST/api/admin/events管理员查看全部状态 / 发布赛事
PATCH / DELETE/api/admin/events/{id}完整编辑 / 删除赛事
POST / PATCH / DELETE/api/admin/venues[/{id}]新增 / 完整编辑 / 删除地点
POST / PATCH/api/admin/rules[/{id}]新增 / 完整编辑知识资料
GET/api/admin/overview统计、最近查询记录、用户反馈

赛事筛选

支持 q、city、start_date、end_date、longitude、latitude、radius_km、bbox、favorites、sort、page、page_size。日期按区间重叠匹配；坐标为 WGS84，半径单位为公里，距离为球面直线距离。经纬度需同时提供。sort 为 date、newest 或 distance；distance 要求提供坐标。page_size 为 1～100。bbox 为 west,south,east,north。

GET /api/events?city=南京&start_date=2026-10-01&end_date=2026-12-31
GET /api/events?longitude=118.792&latitude=32.023&radius_km=200&sort=distance
GET /api/events?favorites=1

{"items": [...], "total": 10, "page": 1, "page_size": 100}

错误返回

{"error":{"code":"forbidden","message":"需要管理员权限"}}

常见状态码：400 输入校验失败、401 未登录、403 权限或 CSRF 校验失败、404 资源不存在、409 数据冲突、415 内容类型错误、429 请求限流、500 服务内部错误。

新建资源返回 201；编辑和删除返回 200。PATCH 编辑接口要求提交完整表单字段。更多实现说明见项目 README。
