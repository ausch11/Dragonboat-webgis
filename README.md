# 舟行 · 龙舟赛事智能地图

基于 HTML/CSS/JavaScript、Python 和 SQLite 开发的 WebGIS 赛事平台，支持管理员发布赛事、用户地图检索与收藏，以及规则检索和自然语言赛事查询。

## 快速启动

需要 **Python 3.10 或以上版本**，无需安装第三方 Python 包、Node.js 或数据库服务。

```bash
git clone https://github.com/ausch11/dragonboat-webgis.git
cd dragonboat-webgis
python server.py
```

在浏览器中打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。保持终端运行，按 `Ctrl+C` 停止服务。Windows 用户也可以双击 `启动项目.bat`。

若 8000 端口被占用，执行 `python server.py --port 8001`，然后访问 [http://127.0.0.1:8001](http://127.0.0.1:8001)。

## 基本使用

1. 使用管理员账号登录，进入“管理工作台”，新增比赛地点并发布赛事；草稿仅管理员可见。
2. 使用普通用户账号登录，在“赛事探索”或“赛事地图”中查看已发布赛事。
3. 按日期、城市筛选。需要距离筛选时，选择参考地点或输入经纬度，再设置查询半径；地图支持拖动、缩放及点击地点查看赛事。
4. 点击赛事卡片的“收藏”，在“我的收藏”中查看。点击“查看全部”可清除筛选条件。
5. 在“知识助手”中提问，例如“南京附近200公里有哪些赛事？”或“参赛需要哪些安全装备？”。规则回答附有资料来源，赛事结果可以打开详情。

地图默认使用本地示意底图；点击“在线底图”可加载 OpenStreetMap 地图，需要网络。距离为直线距离。

## 数据与配置

- 首次启动自动创建 `data/app.sqlite3`，写入演示账号、8 个地点、10 场赛事和 6 条知识资料；后续启动保留已有数据。
- 示例赛事和知识仅用于演示。赛事日期主要在 2026 年 10～12 月，并含历史记录；列表默认从今天起筛选，点击“查看全部”可查看历史赛事。
- 赛事图片位于 `web/assets/`。替换图片后，可在管理员编辑赛事时修改封面路径，例如 `/assets/nanjing.jpg`。
- 默认问答使用本地检索和数据库查询，不需要模型密钥。可将 `.env.example` 复制为 `.env`，填写 `LLM_API_URL`、`LLM_API_KEY`、`LLM_MODEL`，重启后接入支持工具调用的 Chat Completions 兼容服务。URL 必须为完整 HTTPS 接口地址；模型调用失败时回退本地模式。
- 数据库、日志和 `.env` 已加入 Git 忽略规则。初始化密码配置仅在创建新数据库时生效。

运行后的 [API 文档](http://127.0.0.1:8000/api-guide.html) 可查看接口说明。

## Docker 启动（可选）

安装 Docker 后，在项目目录执行：

```bash
docker compose up --build
```

访问地址仍为 [http://127.0.0.1:8000](http://127.0.0.1:8000)，数据库保存在 Docker 命名卷中。
